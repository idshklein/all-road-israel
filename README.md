# כל הדרכים מובילות אליכם

מפת דפדפן אינטראקטיבית: בוחרים נקודה על המפה, ורשת הדרכים מצוירת כעץ מסלולים אליה. העץ מחולק לשישה ענפים צבעוניים, והפוסטר בסגנון נייר בהיר עם מקרא זמין להורדה כ־PNG או SVG.

בהשראת [CuencasTrafico](https://github.com/Ntizar/CuencasTrafico).

## הפעלה

מתיקיית הפרויקט:

```powershell
python -m http.server 8000
```

פתחו בדפדפן את <http://localhost:8000>. נדרש שרת מקומי כדי לטעון את קובץ הנתונים.

## נתונים וחישוב

- `data/roadnumbers_source.zip` — קובץ ה־SHP המקורי שהורד מ־Data.gov.il.
- `data/roadnetwork.geojson` — קווי השכבה אחרי חיבור צמתים, פישוט גאומטריה והמרה ל־WGS84. הקובץ כולל גם קישורים שאינם נושאים מספר דרך כדי לשמור על רציפות הרשת.
- מקור: [משרד התחבורה והבטיחות בדרכים — מספרי דרכים ארציות](https://data.gov.il/dataset/roadnumbers), רישיון CC BY. השכבה עודכנה במאגר ב־22 ביולי 2026.

לחיצה על המפה מצמידה את היעד לכביש הקרוב ביותר. העץ מחושב לפי מרחק גאוגרפי, לא לפי זמן נסיעה; עובי הענף מייצג את מספר הצמתים שממשיכים ממנו, ולא נפח תנועה. צמתים נוצרים ממפגשי הקווים בשכבה, ולכן מעברים מפלסיים או קישורים חסרים עלולים להשפיע על הרציפות. זו המחשה של רשת הדרכים, לא כלי ניווט.

אפשר להזיז ולהגדיל את המפה, ולהוריד פוסטר PNG או SVG של היעד והענפים שנבחרו.

לפרטים על מקור הנתונים, מבנה המטא־דאטה, תהליך העיבוד, חישוב הענפים והמגבלות ראו [מתודולוגיה](./METHODOLOGY.md).
